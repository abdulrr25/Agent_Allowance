How it holds

Protocol layer: a NEAR FunctionCall key cannot attach tokens and is locked to a single contract, so a fully leaked agent key cannot move value itself or reach anything else on NEAR. Contract layer: the vault enforces the amounts. On most chains a key does whatever the account can; reproducing the first layer elsewhere needs an account-abstraction stack.
