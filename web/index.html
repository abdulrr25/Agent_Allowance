The problem

A model cannot tell an instruction from a fact.

Your prompt, a web page it reads, an email it parses — it all arrives as one stream of text. Whoever controls any of that text can steer the agent.

It is unsolved

Prompt injection is ranked the top risk for LLM applications by OWASP. Every defence lowers the odds. None closes the door.

It has cost real money

In 2024 an agent called Freysa held a prize pot under one rule: never transfer it. After hundreds of attempts, someone talked it into releasing about $47,000.

A rule in a prompt is more text

A limit written into the agent's instructions or code is something an attacker can argue with or overwrite. A limit enforced by the network is not.

How it works

Two gates. Neither of them reads English.

The agent never holds the money. It holds one key that can do one thing: ask a vault to pay, within rules the owner wrote as code.

Gate 1 · the NEAR protocol

A function-call access key is bound to one contract and a list of methods, and can never attach a deposit. A leaked agent key cannot transfer funds, reach an exchange, or touch anything else on NEAR. Enforced by the network.

Gate 2 · the vault contract

Per-payment cap, rolling 24-hour cap, recipient allowlist, per-agent switch and a global kill switch — the same rules for native NEAR and for every NEP-141 token.

Walk through the whole flow
What the owner controls

A policy per agent, per asset.

Per-payment cap

The most a single request may move. A request above it is refused before anything else is considered.

Rolling 24-hour cap

A budget that refills on its own. Spending is debited before the transfer and restored if the transfer fails.

Recipient allowlist

Up to twenty addresses the agent may pay. Everyone else is refused, whatever the amount and whatever the reason given.

Kill switch

One call pauses every agent; another disables or revokes a single one. Both need the owner's full-access key.

Stablecoins included

NEP-141 tokens run through the same evaluator as native NEAR, so a token policy cannot drift from the rules.

On-chain audit trail

Every allowed and denied request is a NEP-297 event, including the text the agent submitted. It costs no contract storage.
